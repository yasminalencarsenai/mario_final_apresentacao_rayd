NOSSO DESENVOLVIMENTO

Conheça nosso projeto

Nosso projeto consiste no desenvolvimento de um jogo digital de plataforma, no qual o jogador precisa superar obstáculos e alcançar a maior pontuação possível.

Como funciona?

Durante o jogo, o personagem percorre um cenário, desviando de obstáculos e utilizando movimentos para continuar avançando. A cada desafio superado, o jogador acumula pontos.

Desenvolvimento do jogo

O projeto utiliza HTML para estruturar a página, CSS para criar o visual e as animações e JavaScript para desenvolver a lógica e as interações.

Também utilizamos PHP e MySQL para realizar a comunicação com o banco de dados e armazenar a pontuação dos jogadores em um ranking.

Nosso objetivo

Criar uma experiência divertida e interativa, desenvolvendo um jogo com identidade própria, desafios progressivos e um sistema de pontuação.
